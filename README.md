# RoamBot

支持多人汇合的天气感知风景出行推荐助手。

## 项目简介

用户输入主出发地址、额外 0-2 个同行人地址、最远可接受距离、风景类型和可出行日期区间，系统结合日期区间内每天的天气、地点匹配度、距离和多人公平性，推荐若干风景地点并解释原因。

## API Key 配置

本项目不会提交真实 API key。

本地开发应复制 `.env.example` 为 `.env`，填入真实 key。`.env` 是明文文件，只适合本地开发使用，不应提交到 Git。

Docker 运行时应通过环境变量注入 key，不应在镜像构建阶段写入 key。

## 安全边界

- 不硬编码 API key。
- 不在日志中输出 API key。
- LLM 只根据结构化推荐结果生成解释文本，不自主调用工具。
- 本项目不接入 12306、机票购票或下单能力。
