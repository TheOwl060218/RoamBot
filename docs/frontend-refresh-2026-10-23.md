# 新版前端集中整改

回退点：已上传的fd431e1。本批只改前端、配套测试及说明；backend目录相对回退点没有差异。未改变模型、理解提示、推荐检索/排序、业务权限和请求协议，不部署、不修改8026。

## 已修改的体验

- 参考比赛版DestinationCard的信息层级，保留单行横滑和整卡详情、独立比较动作，收紧大标题和空白。卡片改为按有用内容决定高度，通常约260px、最高350px，宽度保持310px/手机82vw。长营业原文在卡片限制为单行，详情完整显示，不再把整排撑到560px。
- 增加已有体验方向、去重后的地图类型；有营业/消费、路线、天气才展示，不生成新推荐理由，不显示资料依据或恢复匹配指数。不从地图类别推断免费、人少、可躺等特性。
- 推荐内容在上方独立滚动区，聊天区在下方真实布局中占位，不再悬浮覆盖卡片或操作栏。对话记录默认为固定高度的最近记录，可展开历史；消息增多不改变布局高度。选择栏跟随卡片区域，地点名称可移出，两个主要按钮同行；手机按空间换行。
- 详情按信息量收紧，显示类型、完整营业/消费、可用联系电话和天气；补回直接收藏按钮。地图与详情仍沿现有层级历史机制，不改用路由跳页。
- 比较改为同项对齐的表格，包含体验、类型、位置、营业、消费及可用路线/天气；整行都缺的数据不出现，个别缺项用短横线。可从比较查看某个地点详情。
- 新推荐“发起同行计划”打开专用表单，已有日期预填、缺日期在表单选，名称/人数可编辑，直接POST /plans。不再伪造一条用户聊天，不调用模型解析按钮意图；日期仍遵守既有七天业务约束，仅在创建计划时需要，不变成推荐必填项。
- 计划中心发起转到/explore并提示选点流程。收藏的继续探索预填地点与城市，等用户发送，不自动生成付费查询；旧/recommend作为显式兼容入口保留。
- 计划顶部和投票结果统一使用预计总数，并另说清已加入人数/未投票人数。去掉没有实际建议时的“暂无判断”空栏，不借用旧天气建议。
- 手机投票改为独立层级浮层，投票表单使用实色浅海色底，背景交互及助手球暂由模态层隔离；关闭后原入口恢复。桌面仍保留并排工作台。
- 新推荐分享卡片可打开详情、跳转高德位置或继续探索。公开快照不含私有坐标/营业字段，本批不扩大后端公开白名单；位置入口使用地点名称和城市打开高德，未改成伪造内部坐标。
