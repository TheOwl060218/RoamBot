# 对话布局与本轮定位/查询只读核查

## 界面修改

- 删除推荐页工具栏“继续聊这次出游”，无对话时不显示历史开关；有对话时将展开/收起放在记录下方、输入框上方右侧。详情/地图浮层的无障碍聊天入口保留原名。
- 默认记录桌面56px、移动42px；展开桌面最多180px/24svh、移动最多128px/18svh。渐隐区域随展开加大为64px/56px，保留隐藏滚动条、手动滚动和原340ms高度动画。
- 原移动端把整块历史+输入区域sticky到底部，展开会盖住卡片和换批操作。改为与桌面一致的上下两行布局：上方推荐内容实际滚动、下方记录/开关/输入占用独立高度；卡片原尺寸不变。垂直浏览与水平卡片滑动均保留，操作可滚入视口。
- 顶部导航硬背景改为独立伪元素上的14px backdrop blur和渐隐蒙版，不给导航文字加模糊；监听窗口与推荐内容区滚动。推荐滚动区顶部28px、底部18px局部渐隐，避免卡片被硬边切断。
- 推荐和分享卡片的“详情/查看详情”提示胶囊移除；整张卡片的原真实详情按钮仍可用。
