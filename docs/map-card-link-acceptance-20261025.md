# 推荐地图与卡片联动 · 2026-10-25

## 本批范围

- “换一批 / 看看其他区域”同排增加“地图”入口，展示本轮所有已有推荐地点。
- 默认保持编号定位针和真实尖端落点；鼠标进入、键盘聚焦显示名称，离开后恢复当前选中地点名称。名称浮在独立画布层内，按边界左右限位、上下翻转，不改变针的锚点。
- 地图选择同步推荐卡片：桌面侧边、窄屏地图下方。使用已有地点类型、活动、区县、开放时间、费用、路线和天气数据；收藏及加入行程复用原有控件和权限。长开放时间默认两行摘要，展开后看完整内容、地址及电话；没有新生成推荐理由或图片。
- 从结果行入口关闭地图、按 Escape 或浏览器后退，会滚到选中卡片并短暂描边，恢复该卡片的键盘焦点。卡片对象和顺序保持不变。浏览器前进可重新打开地图并保留选择。
- 从原有地点详情进入地图时继续沿用原先“地图→详情→结果”的返回层级；新增卡片区域同样可用。
- 选中地点同步滚动顶部候选条；侧栏切换地点时回到顶部。窄屏滚动长卡片时固定地图标题和关闭按钮。
