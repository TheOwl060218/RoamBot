# 推荐目的地省市范围设计

日期：2026-10-08（Asia/Shanghai）
状态：用户批准设计、实施计划及独立目录调整；正式实现完成，Mock验收后等待用户视觉验收，未提交/推送。
关联：SPEC.md、PLAN.md、docs/PROJECT_HANDOFF.md。

## 1. 目标与已批准体验

用户可以限定推荐目的地所在的多个省、市。默认是“最大距离内不限省市”，不是无限距离的全国搜索。省市只约束目的地，不改变出发地址解析。

仅在“推荐地点”模式显示；“评估指定地点”不使用此筛选。切换模式保留地区草稿，评估请求不携带地区字段。游客仍能推荐，收藏、历史、发起计划的认证规则不变。

界面采用已批准 Demo：最大距离旁的目的地范围可直接输入；下方浮层显示真实省市目录中的匹配项，不用 AI 猜测。输入本身不是选中，点击候选或按 Enter 才确认。

- 只有外层圆角边框；聚焦时整栏浅青高亮，不出现内部粗框。
- 右侧“选择”按钮有完整文字与足够触控区域，替代细小下箭头。
- 已选胶囊放在框内，固定单行高度；放不下的项目以 `+N` 显示。展开后可查看和移除全部选择。
- 候选浮层不参与文档流，不推动风景偏好、提交按钮等内容。复用现有浮层定位思路，避免左右工作区 overflow 裁切；窄屏向可用区域定位并限制长度。
- ArrowUp/ArrowDown 移动候选，Enter 选择，Escape、外部点击或完成选择关闭；输入法组合期间 Enter 不选中。
- 选择全省合并所属城市；已经选择全省时，其下城市标为已覆盖，不重复添加。删除省级选择不自动恢复此前合并的城市。
- 地区目录无匹配时明确提示，不接受任意自由文本作为行政地区。
- 未确认的输入不能悄悄作为筛选或悄悄丢弃后提交；提交时提示“请从候选中选择省市，或清空未选择的输入”。复用现有两秒错误胶囊。
- 不更改原有 ScenerySelector、偏好匹配、权重、同行出发地及页面主题。Demo 中简化风景标签不作为正式设计。

## 2. 当前代码发现

RecommendationRequest 尚无地区范围字段；Destination 只有 city，不能可靠区分省份或同名地区。AMapProvider._place_params 当前使用 `region=city` 与 `city_limit=true`；MockPlaceProvider 同样只查请求城市。CachedPlaceProvider 的缓存键不含地区范围。

因此只加前端或仅对旧候选做过滤都不够：跨城市候选必须先能进入候选池。历史存储完整请求 JSON，可兼容新增缺省字段；无需新增数据库列。QuerySummary 当前部分路径读取草稿，不能用于证明某次查询实际采用了哪些地区。

## 3. 数据与接口

来源调整（2026-10-08）：高德下载表用途限制后，用户批准独立目录，不将高德下载表用作应用目录。

版本化目录采用modood/Administrative-divisions-of-China固定提交c49d495b40ac73eb1a66f6eeae5f8fd10696f035（WTFPL-2.0）。来源/许可证/归一化源文本SHA256见docs/legal/REGION_DIRECTORY.md。数据截止2023-06-30，源项目已停更，仅收录大陆31省级地区，不宣称最新、覆盖港澳台或等同高德所有编码版本。前端可选396项：省级、地级及显式省直辖县级条目；普通县区仅在私有归属索引。字段为adcode/name/level/province_adcode；只用显式索引，不截断未知编码猜父级。行政区变更需要维护新版本。

新增只读 `GET /api/v1/regions`：返回version/data_date/source/license及regions，不公开县区索引；无需登录/Provider/密钥。首次打开/输入或恢复已选地区时加载并内存缓存，失败可重试，不接受自由文本。

RecommendationRequest 增加 `destination_regions: list[str] = []`，内容为已选目录 adcode。后端校验存在、层级允许，去重并做全省覆盖合并；规范顺序用于缓存。目录可选项数量即有限上界，接口不接受超出目录规模的列表。不额外引入用户尚未批准的固定“最多选几个”限制。

Destination 增加可选 `province_adcode`、`city_adcode`、`adcode`；旧快照缺失时仍可读取。来自高德的编码按目录归属规范化。受限查询不能用请求 city 兜底猜测目的地归属；归属缺失或不明确的候选不进入受限结果，并返回适当数据缺失提示。不限查询允许旧数据继续使用，不能伪造行政编码。

地区谓词是 OR：江苏全省或杭州市均可进入；再与主出发地最大距离及原风景规则求交集。距离仍按现有主出发地路线/降级估算语义，不改成所有同行人都在此半径内。

## 4. 候选发现及调用边界

推荐搜索保留出发城市作为 geocode/suggest 提示，但不再把它当作目的地硬边界。PlaceProvider.search 增加可选范围参数，Mock、AMap、缓存包装和测试替身一起更新。

选择空间查询而不是按每个省市新增一组外部请求，避免多选导致调用数成倍增长：

- 不超过 50 km：使用现有周边搜索，取消出发城市硬限制；按实际返回归属过滤已选地区。
- 超过 50 km：使用高德文档中提供的矩形多边形 POI 搜索 `/v3/place/polygon`。矩形由主出发坐标与距离计算，覆盖圆形范围；随后仍做球面距离预筛，避免矩形角落超距。不再回退为出发城市限定的文本搜索。
- 每个风景类型最多一次 POI 网络查询，每次最多25条；类型总数最多6。空结果不另行扩大范围或递归补查。保留既有服务预算，并增加真实 HTTP 次数契约测试，不把外层一次 search 当成一次真实请求。
- 先做地区/空间/类型筛选，再做候选合并去重与配额；不能在筛选前截取25个导致全部被无关城市占满。
- 后续仍按原流程测路程、查天气、排名和解释。省市筛选不改变分数定义、天气规则或选择数量策略。
- 有限候选检索不是穷举。展示“当前检索到的候选”而非“该地区没有景点”；只找到少数或没有候选时不跨出已选地区、不加大距离。
- v3 POI 的评分、行政编码字段单独解析；不把 v5 business 结构套用到 v3，不编造缺失评分。
- 无法调用新空间接口时按既有 Provider 失败语义反馈，不暗中回退旧同城结果。用户 Live 权限、额度与实际结果需后续人工 smoke，自动测试仅 Mock/HTTP fixture。

缓存键加入范围版本和规范化地区集合，并更新搜索算法版本。不同范围不共用旧缓存；新区域字段采用缺省值支持旧持久化快照，不批量重写或删除用户数据库。

## 5. 草稿、历史、摘要与计划

- TravelFormDraft 保存已选编码；旧草稿缺字段按不限处理。输入中的未确认字符仅属于当前编辑状态，不持久化为筛选。
- 推荐请求及 session 结果保存实际提交的地区。QuerySummary 展示 query_request，不能随着表单编辑而改变已展示结果的条件。旧结果无 request 时按兼容逻辑处理，不声称其已按新范围筛选。
- 登录后显式重新推荐、历史 rerun 和历史回填保留地区；旧历史缺字段按不限新语义重新检索，不修改旧结果快照。
- 改变省市只是改变下一次推荐条件，不会自动触发真实查询或把旧结果转为可信结果。
- 计划候选从该次可信推荐历史复制，地区不会成为投票或天气检查的新限制。不修改已有计划。公开分享继续沿用原白名单，不顺带公开出发地址或新增请求正文。

## 6. 受影响模块与验收

领域模型/地区目录、地区只读路由、推荐服务、AMap/Mock/Cached Provider；前端 API 类型、RegionInput、TravelForm/formState、QuerySummary 和历史回填；对应测试和交接。SPEC.md/PLAN.md 在批准后追加本功能范围，不覆盖历史证据。

必须先 RED 后 GREEN：

1. 默认不限：跨市且距离合格的 fixture 可入选；出发 city 不成为目的地限制。
2. 多选 OR、全省覆盖、非法编码拒绝、归属未知排除、距离与地区相交，超距不入选。
3. 高德周边无同城硬限制；大半径矩形查询；行政字段及 v3 评分解析；最多六次真实 POI 请求，无多选倍增；缓存范围隔离。
4. 框内固定高度、多选溢出 `+N`、完整选择可删除、搜索/Enter/输入法/ Escape、未确认字符提交提示、目录失败重试。
5. 桌面与手机展开候选不移动下方控件，不裁切、不遮住必要关闭动作；外层只有一个焦点边框，“选择”按钮易操作。
6. 保留原风景选择与权重，评估模式不提交地区，切回推荐保留草稿。
7. 游客推荐、登录确认重查、历史回填/rerun、实际请求摘要及旧草稿/旧快照兼容。

最终验证：pytest/Ruff、Vitest/ESLint/tsc/build，以及隔离 Mock 的桌面/手机 Playwright。只用新测试数据目录，不启动或停止用户8000/5173，不改 data-competition-demo。真实高德、远程部署、真实手机、行政目录长期变化不归为本轮已验证。

## 7. 选择理由和停止点

仅前端筛选旧同城候选不能实现用户目的；逐省市扩大搜索会放大调用；选择“按距离空间发现 + 后端行政归属硬过滤”，保持多选与外部调用数解耦。代价是有限页候选覆盖和 v3/v5 解析兼容必须明确测试，不承诺全量。

官方核验来源（2026-10-08）：https://lbs.amap.com/api/webservice/guide/api-advanced/search ，周边半径0～50000米；提供矩形多边形搜索；返回不保证全量，分页也有限制。上述设计是应用侧选择，不代表用户账户已拥有 Live 权限。

用户已批准并完成正式实现。旧历史原请求JSON不补写字段，前端恢复/显式rerun缺省兼容；旧session结果无query_request时不借新草稿声称地区范围。证据见DESTINATION_REGION_PROGRESS.md。未做Live、真实手机、Docker镜像构建或公网部署；未安装依赖、未提交/推送。
