# RoamBot Favicon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the default browser globe with the approved minimal compass favicon.

**Architecture:** Serve one self-contained SVG from Vite's `public` directory and reference it from the document head. Verify the browser-facing contract through the real HTML document and asset files, then run the production build.

**Tech Stack:** Vite 8, Vitest 4, SVG, HTML

## Global Constraints

- The favicon uses a transparent background and one solid color at a time.
- The icon is a thin circular outline with a simple four-point compass needle.
- The icon contains no text, gradients, shadows, or external dependencies.
- No page logo, layout, application behavior, backend, deployment configuration, or credentials may change.

### Task 1: Add And Reference The Compass Favicon

**Files:**
- Create: `frontend/tests/favicon.test.ts`
- Create: `frontend/public/favicon.svg`
- Modify: `frontend/index.html`

**Interfaces:**
- Consumes: Vite's public-directory mapping, where `frontend/public/favicon.svg` is served as `/favicon.svg`.
- Produces: a document-head `<link rel="icon" type="image/svg+xml" href="/favicon.svg" />` and a valid SVG icon asset.

- [x] **Step 1: Write the failing browser-contract test**

```ts
import { readFileSync } from 'node:fs'
import { resolve } from 'node:path'
import { describe, expect, it } from 'vitest'

const frontendRoot = process.cwd()

describe('favicon', () => {
  it('publishes a valid SVG icon from the document head', () => {
    const html = readFileSync(resolve(frontendRoot, 'index.html'), 'utf8')
    const document = new DOMParser().parseFromString(html, 'text/html')
    const iconLink = document.querySelector<HTMLLinkElement>('link[rel="icon"]')

    expect(iconLink?.type).toBe('image/svg+xml')
    expect(iconLink?.getAttribute('href')).toBe('/favicon.svg')

    const svg = readFileSync(resolve(frontendRoot, 'public/favicon.svg'), 'utf8')
    const svgDocument = new DOMParser().parseFromString(svg, 'image/svg+xml')

    expect(svgDocument.querySelector('parsererror')).toBeNull()
    expect(svgDocument.documentElement.getAttribute('viewBox')).toBe('0 0 32 32')
  })
})
```
