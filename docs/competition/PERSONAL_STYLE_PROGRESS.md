# 个人页面样式对齐 · 2026-10-08

## 范围与根因

以现有推荐页为基准，不重新设计业务或布局。personal.css中收藏列表、收藏详情、历史行和历史更多菜单四处使用不存在的圆角变量，浏览器计算为0px，导致截图中的直角框。

修复为已定义的10px控件圆角与16px卡片圆角；收藏选中边框沿用推荐候选的浅青混色，详情/历史恢复共享轻阴影。个人页面旧绿色操作边框改用主题青色混色；危险操作仍保持红色。其他样式检查覆盖推荐、表单、登录/确认、分享及计划CSS，没有将胶囊、表格、不同层级面板强制改成同一种圆角，也未改状态语义。
