# 阶段1：账户登录

1. 打开 RoamBot 首页，点击“登录”。
2. 在“用户名”和“密码”中输入已注册的演示账号信息。
3. 点击“登录”，再点击“开始查询”。

# 阶段2：自然语言录入条件

1. 点击底部聊天框，输入“我从苏州站出发，明天出发，玩两天，100公里以内，想去湖边、古镇或者博物馆。”
2. 点击聊天框右侧的发送箭头。
3. 再输入“还有一位同行者从上海虹桥站出发。”，点击发送箭头。

# 阶段3：修改条件与推荐偏好

1. 点击“日期”条件卡，点击“这周末”，点击“保存条件”。
2. 点击“目的地范围”条件卡，在“最大距离（km）”中输入“150”，点击“保存条件”。
3. 点击聊天框左侧的四格图标，点击“手动填写条件”，点击“推荐偏好”。
4. 点击权重条中天气与路程之间的分界点，按两次键盘右方向键，点击“保存条件”。

# 阶段4：生成推荐与浏览结果

1. 点击“开始推荐”。
2. 在推荐卡片区域横向滚动，依次查看地点。
3. 点击最左侧的推荐卡片。

# 阶段5：地点详情、地图与场景对话

1. 在地点详情中向下滚动，查看“逐日天气与提醒”和“每位同行者的路程”。
2. 点击“匹配指数如何计算”。
3. 点击“查看位置”。
4. 点击地图顶部的另一个地点名称，再点击原来的地点名称。
5. 点击地图左下方的对话圆球，在聊天框输入“这个地点的天气和路程怎么样？”，点击发送箭头。
6. 点击对话圆球收起聊天框，再点击地图右上角的关闭图标。

# 阶段6：收藏地点

1. 在地点详情中点击“收藏地点”。
2. 点击“← 返回地点”，再点击顶部“收藏”。
3. 点击刚收藏的地点卡片。
4. 点击“← 返回收藏”，再点击顶部“推荐”。

# 阶段7：多地点比较

1. 点击第一个推荐卡片中的“加入比较”。
2. 点击另一个推荐卡片中的“加入比较”。
3. 点击已选栏的“查看对比（2）”。
4. 在比较面板中向下滚动。
5. 点击“收起对比”。

# 阶段8：创建同行计划

1. 点击已选栏中的“发起同行计划”。
2. 在“计划名称”中输入“周末一起去苏州”。
3. 在“预计同行人数”中输入“2”。
4. 点击“确认创建”。

# 阶段9：邀请同行与投票

1. 点击“管理计划”，点击“生成邀请”，点击“分享 / 复制邀请”。
2. 打开浏览器无痕窗口，在地址栏粘贴邀请链接并打开。
3. 在“临时昵称”中输入“小林”，点击“加入计划”。
4. 点击“去投票”，点击第一个地点的“首选”，勾选第二个地点的“可接受”，点击“提交投票”。
5. 点击“修改投票”，将第二个地点改为“首选”，勾选第一个地点的“可接受”，点击“保存修改”。

# 阶段10：汇总投票与确定目的地

1. 切回发起者窗口，刷新计划页面。
2. 点击“去投票”，点击第一个地点的“首选”，勾选第二个地点的“可接受”，点击“提交投票”。
3. 点击“检查天气”。
4. 点击“结束投票”，再点击“确认结束投票”。
5. 点击第一个候选地点中的“选为目的地”，再点击“确认决定”。
6. 切回无痕窗口，刷新邀请页面，再切回发起者窗口。

# 阶段11：历史查询与结果分享

1. 点击顶部“历史”，点击最近一条“地点推荐”记录。
2. 点击顶部“历史”，点击这条记录右侧的省略号，点击“重新查询”。
3. 点击顶部“历史”，点击最新推荐记录右侧的省略号，点击“创建分享”，再点击“复制链接”。
4. 在无痕窗口中新建标签页，粘贴分享链接并打开。
5. 在分享页向下滚动查看推荐地点，再切回发起者窗口。

# 阶段12：指定地点评估

1. 点击顶部“推荐”，点击“← 返回修改”。
2. 点击聊天框左侧的四格图标，点击“评估指定地点”。
3. 在“目标地点”中输入“苏州金鸡湖景区”，点击对应的地点候选。
4. 点击“保存条件”，点击“评估这个地点”。
5. 点击评估结果卡片，在详情中查看逐日天气和各出发地的路程。
6. 点击“← 返回地点”。

# 阶段13：计划中心回顾

1. 点击顶部显示城市和日期的计划胶囊，进入当前计划。
2. 点击页面左上的“计划中心”，进入计划列表。
3. 点击“周末一起去苏州”的计划卡片。
4. 向下滚动，查看最终目的地和投票结果。
