# 2026-10-09 页面内景点位置地图

## 已确认范围

用户优先需要景点评价；公开POI接口未提供完整用户评论列表，所以本轮不抓取或虚构评论。用户接受站内位置地图，并明确入口不能叫“站内地图”，采用「查看位置」和「打开高德」。

- 查看位置：本页弹窗，地图按需加载，显示当前查询候选，点击候选或标记同步选中；不请求用户定位，不显示出发地。
- 打开高德：新页面按景点名称＋城市搜索。详情及评价仍由高德提供，可能要求登录，登录后保留搜索条件由高德控制，不能承诺。
- 弹窗手机适配、Esc/关闭/遮罩关闭、恢复焦点和滚动；地图加载失败或未配置不影响推荐，可重试。
- 本轮不增加图片、营业时间或评论采集；不修改天气评分、Provider、数据库、套餐、副本或主分支。

## 安全与配置

Railway现有服务 Variables，由用户自行填写，不在聊天、代码、截图或日志中暴露值：

| 变量名 | 来源 |
| --- | --- |
| ROAMBOT_AMAP_JS_KEY | 新建的Web端（JS API）Key，不是既有Web服务Key |
| ROAMBOT_AMAP_JS_SECURITY_CODE | 该JS API Key配套安全密钥 |

用户已表示两个变量添加完成。运行时配置接口仅返回浏览器SDK必要的JS Key和代理地址，不返回securityJsCode。JS Key在浏览器SDK请求中可见，这是SDK接入方式；配套安全密钥始终在服务端，不能与浏览器Key混淆。若控制台支持域名白名单，配置生产域名 `roambot-production.up.railway.app`；真实权限/配额仍需人工检查。

使用[官方安全代理方式](https://lbs.amap.com/api/javascript-api-v2/guide/abc/jscode)，固定上游HTTPS主机，只放行本轮地图样式与矢量地图路径，不允许搜索/任意代理；忽略客户端key/jscode，不转发Cookie或客户端头，不跟随重定向。上游8秒超时、响应2MB上限，整个单进程代理每分钟最多60请求，未知路径404，未配置503，失败502。无任意HTML拼接，景点标记使用textContent。没有读出用户密钥或更改原有Web服务Key。

## 发布后人工验收

1. 刷新页面，生成一次推荐；「查看位置」留在原页并显示真实地图，可拖动缩放。
2. 选择另一个候选或地图标记，地图/弹窗名称及外部高德搜索目标同步。
3. 关闭后原查询保留；桌面Esc可关闭，手机无标题遮挡或横向溢出。
4. 「打开高德」在外部打开，检查景点名称和城市；高德登录/评论可用性自行确认。
5. 若提示未配置，检查两变量名称及Railway部署已应用；加载失败仅提供错误提示截图，不发送密钥或带Key的网络URL。
