## 关键验收断言

- 收藏第二个必须对应真实查询第二个地点 ID；创建后数据库仅有一项计划，重放不重复创建。
- 另一用户或新登录会话不能执行原方案；跨用户历史不能用于收藏或建计划。
- 模拟服务端已提交但响应丢失时状态标为 uncertain，禁止重复写入。
- 条件追问时状态 awaiting_input，旧选择不能继续创建计划。
- 接受/首选部分修改保留另一字段；匿名身份同批加入后可投票，Secure Cookie 保持。
- 地图关闭只回详情，再关闭详情回结果；聊天不引发 query 整页转场。
- 收藏详情的聊天位于该浮层内；外部助手在 inert 时隐藏，不造成两套可交互入口。
- 当前页面列表序号只在服务端已授权对象中按显示顺序绑定；无效 ID 不回退为另一个对象。

## 研究和实现取舍

- [Anthropic 工具设计](https://www.anthropic.com/engineering/writing-tools-for-agents)：以业务任务组织工具，复用已有服务，不暴露任意 HTTP 执行。
- [Qwen Function Calling](https://docs.modelstudio.console.alibabacloud.com/en/model-studio/qwen-function-calling)：核对多工具与 tool_choice 的模型差异。本项目当前网关启用 parallel_tool_calls 后仍遗漏后续步骤，采用有序步骤函数合同并实测。
- [τ²-bench 评估](https://github.com/sierra-research/tau2-bench/blob/main/docs/evaluation.md)：参考最终状态验收思想，本地检查实际数据库和页面状态，不用模型自称成功作为证据。

## 限制

这是一版全范围接入，测试覆盖不等于所有表达都稳定正确。真实模型验收用现有 `qwen3.7-plus`，真实调用仅限模型；未调用真实高德/天气。未部署、未做生产迁移，未实测真机/Safari。工具化没有替代原有地点角色、日期角色和多轮条件理解评估。
